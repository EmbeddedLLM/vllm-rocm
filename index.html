vLLM ROCm PyPI Repository

This is a custom PyPI repository for vLLM with ROCm support and all dependencies.

📦 Hybrid Storage: Small wheels (<100MB) are hosted on GitHub Pages, while large wheels (PyTorch, Triton) are hosted on GitHub Releases for better performance.

Installation

pip install vllm-rocm --index-url https://EmbeddedLLM.github.io/vllm-rocm/simple/
